# NOISE MU6IX — WRECKAGE (v1.0.0)

Cinematic Ensemble Percussion & Modern Drum VST3 Engine (`WRECKAGE.vst3` + `WRECKAGE Player.vst3`) built by **Noise Mu6ix Studio**.

## GitHub-ல் அப்லோட் செய்து Windows `.vst3` Build எடுப்பது எப்படி?
1. ZIP-ஐ Extract செய்து `NOISE-MU6IX-WRECKAGE` உள்ளே உள்ள கோப்புகளை உங்கள் GitHub Repository-ல் அப்லோட் செய்யவும்.
2. **Actions** டேப்பில் `Build NOISE MU6IX WRECKAGE (Windows VST3)` முடிந்ததும் **Artifacts** பகுதியில் **`NOISE_MU6IX_WRECKAGE_v1.0.0_Windows_x64.zip`** கோப்பைப் பதிவிறக்கவும்.
3. அதில் உள்ள `WRECKAGE.vst3` மற்றும் `WRECKAGE Player.vst3` இரண்டையும் `C:\Program Files\Common Files\VST3\` ஃபோல்டரில் போட்டு FL Studio-வில் Scan செய்யவும்.
