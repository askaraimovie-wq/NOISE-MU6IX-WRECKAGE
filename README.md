# NOISE MU6IX - WRECKAGE (v1.1.1)

Cinematic Ensemble Percussion & Modern Drum VST3 Engine (`WRECKAGE.vst3`) built by **Noise Mu6ix Studio** for **Windows (x64)** and **macOS (Universal: Apple Silicon arm64 + Intel x86_64)**.

## Installation
- **Windows (x64):** Copy `WRECKAGE.vst3` to `C:\Program Files\Common Files\VST3\`
- **macOS (Universal):** Copy `WRECKAGE.vst3` to `/Library/Audio/Plug-Ins/VST3/` (or `~/Library/Audio/Plug-Ins/VST3/`)
  - If macOS Gatekeeper flags the downloaded unsigned bundle, run: `xattr -cr /Library/Audio/Plug-Ins/VST3/WRECKAGE.vst3`
